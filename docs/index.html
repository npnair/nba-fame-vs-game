      Weight the fame signals yourself

      Fame is a weighted blend of five signals, each ranked against the rest of the league. Drag a slider to change how much it counts. The chart updates instantly. A player missing a signal is scored on the ones they have.

      How it works

      Game

      On-court value from Basketball-Reference: half VORP (total value, which rewards playing time) and half BPM (value per possession), ranked within each season. Last season carries the score early on, and 2026–27 takes over as minutes pile up.

      Fame

      Five signals, each turned into a percentile: English Wikipedia page views over the last 30 days, news articles mentioning the player in the last 30 days (Google News, counted daily), Instagram and TikTok followers, and film and TV credits (Wikidata).

      Verdict

      Both scores are percentiles from 0 to 100. A player whose game outranks their fame by 25 points or more is underrated, and the reverse is overrated. Quadrants split at 50.

      Pipeline

      A GitHub Actions job pulls every source each morning, a dbt project on DuckDB cleans and models the data, and tests check it before this page updates. Follower counts are entered by hand monthly from public profiles.

      Sources: Basketball-Reference, Wikimedia page views, Google News, Wikidata, public Instagram and TikTok profiles. Code on GitHub.
